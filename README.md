========================================
              pyDDnet
========================================

Клон DDnet на Python — потому что почему бы и нет?

  Made by Claude free

========================================
              УСТАНОВКА
========================================

1) Установите Python
   Скачайте с официального сайта (python.org) и установите.

2) Настройте окружение
   Запустите setup.bat и дождитесь завершения установки
   всех зависимостей.

3) Запустите клиент
   run_client.bat

   Если у вас DDnet установлен через Steam — клиент
   автоматически найдёт папку с картами.
   Если нет — укажите путь вручную через командную строку:

   run_client.bat --ddnet "C:\Полный\путь\к\папке\DDnet"
